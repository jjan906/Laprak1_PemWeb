Bagian II

Jawaban Teori

1. Tentang Tag

Jawaban 1a

Tag HTML adalah kode petunjuk untuk browser agar mengetahui bagaimana konten ditampilkan. Semua website dibangun dari kumpulan tag. Contohnya <p>, <h1>, dan <img>.

Jawaban 1b

Tag pembuka digunakan untuk memulai, dan tag penutup untuk mengakhiri seperti <p> dan </p>. Tidak semua tag punya penutup, seperti <img> dan <br>.

2. Tentang Element

Jawaban 2a

Element adalah bagian lengkap HTML yang terdiri dari tag pembuka, isi, dan tag penutup.

Jawaban 2b

Tagname adalah nama tag seperti p atau h1. Attribute adalah tambahan seperti href. Content adalah isi di dalam tag.

Jawaban 2c

Elemen bisa ditumpuk (nested). Namun harus berurutan dengan benar, jika tidak bisa menyebabkan error atau tampilan rusak.

3. Tentang Anchor

Jawaban 3a

Anchor adalah tag untuk membuat link menuju halaman lain atau bagian tertentu.

Jawaban 3b

Anchor bekerja dengan atribut href. Saat diklik, browser akan menuju alamat tersebut.

4. Tentang Multimedia

Jawaban 4A

Tag teks: <b>, <i>, <strong>, <em>, <p>, <h1>.

Jawaban 4B

Gambar menggunakan <img>. Jika tidak tampil biasanya karena path salah. Atribut alt digunakan sebagai teks pengganti.

Jawaban 4C

Audio menggunakan <audio>, bisa dari file lokal atau internet.

Jawaban 4D

Video menggunakan <video>. Untuk autoplay biasanya perlu atribut muted.
